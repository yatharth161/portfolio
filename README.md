# Yatharth Hingane — Portfolio

A responsive, editorial-style portfolio built with **HTML and CSS**. It uses no JavaScript, so the mobile navigation, visual effects, and page layout are CSS-first.

## Run locally
1. Extract the ZIP file.
2. Open the `yatharth-portfolio` folder in VS Code.
3. Open `index.html` in your browser. The VS Code Live Server extension is optional.

## Add your profile photo
Replace `assets/images/profile-placeholder.svg` with your photo file, then update the image `src` in `index.html` to match the filename (for example, `assets/images/profile.jpg`). Use a well-lit portrait with a simple background for best results.

## Update projects and certificates
The Projects and Certifications sections are intentionally marked as waiting for your details. Replace their placeholder content only after you provide the real project names, descriptions, technologies, links, and certificates.

## Contact links
The portfolio currently includes the GitHub, LinkedIn, Instagram, and email links provided by you. Check them in a browser before publishing. No JavaScript is used.

## Notes
- Main page: `index.html`
- Styles: `assets/css/style.css`
- No JavaScript file or framework is required.
- The contact section spans the full viewport width; CTA hover states use CSS-only lift, color, and underline effects.
- Typography uses Google Fonts when online; system fallbacks are defined.
